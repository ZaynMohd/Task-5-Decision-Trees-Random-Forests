# Task 5 - Decision Trees and Random Forests

## Objective

Build and compare Decision Tree and Random Forest models for classification.

## Dataset

Breast Cancer Wisconsin Dataset from Scikit-learn.

## Work Done

- Trained a Decision Tree Classifier
- Visualized the decision tree
- Analyzed overfitting using different tree depths
- Trained a Random Forest Classifier
- Compared Decision Tree and Random Forest accuracy
- Analyzed feature importance
- Evaluated models using 5-fold cross-validation
- Created confusion matrix and performance visualizations

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Conclusion

Random Forest was compared with a single Decision Tree using test accuracy
and cross-validation. Feature importance was also analyzed to understand
which features contributed most to the predictions.
